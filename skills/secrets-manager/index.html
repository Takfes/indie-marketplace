Profile

Bound project paths

Absolute paths, one per line. When the working directory matches one of these, this profile is selected automatically.

Active Profile

The profile used when INDIE_PROFILE is not set in the environment and the current working directory matches none of a profile's bound project paths.

base holds the inherited defaults every profile falls back to. active decides which profile applies right now. Setting active to base is valid — it just means no profile-specific overrides are in play.
